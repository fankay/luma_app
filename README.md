# Luma 图片工作台

使用 SwiftUI、AppKit 与 ImageIO 开发的原生 macOS 应用。需要 macOS 14+、Xcode 16+，无第三方运行时依赖。

## 运行

使用 Xcode 打开 `Package.swift`，选择 Luma 并运行；或执行：

```sh
bash scripts/build-app.sh
open build/Luma.app
```

## 功能

- 批量拖放与文件选择，图片预览与尺寸展示。
- HEIC、JPEG、PNG、TIFF 格式导出，输入支持系统 ImageIO 可解码的静态图片。
- 高质量压缩：使用 Apple 原生编码器，HEIC / JPEG 可调质量，默认 88%。这是有损编码，不能保证画质完全无损。
- 严格无损：保留输入格式，对重新编码结果进行像素数据与色彩空间一致性检查，仅在检查通过且文件更小时采用，否则直接保留原始文件字节。已压缩图片可能无法继续缩小。
- 保留原文件、自动避免同名覆盖、逐文件错误反馈、导出体积统计。
- 深色原生界面、启动渐入与位移动画、处理进度动画，响应系统减少动态效果设置。

## 验证

```sh
swift test
```

编码集成测试覆盖四种目标格式、输出可解码、无损输出不增大、重复输出文件名及源文件保持不变。

## 当前边界

多帧/多页文件会被明确拒绝，避免静默丢失内容。包含透明通道的图片转换 JPEG 会被拒绝，请使用 PNG / HEIC。高质量模式尝试携带源元数据，但跨格式不保证所有厂商元数据、HDR 辅助图或特殊色彩信息完整保留；有存档需求请使用严格无损模式。应用包采用本机临时签名，公开分发前需配置开发者签名与公证。
